# Fragen importieren
Der Dialog zum **Importieren von Fragen** kann aus dem [Kategorie-Baum](../Ordnerverwaltung/index.md) über das [Kontext-Menü](../Ordnerverwaltung/index.md#kontext-menü) aufgerufen werden.

Importiert werden .lto-Dateien, deren Aufbau unter [LTO-Dateiformat](../../lto/index.md) beschrieben ist.
