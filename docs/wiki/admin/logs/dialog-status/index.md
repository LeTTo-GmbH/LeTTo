# Dialog: Fortschritt einer Hintergrundtransaktion

Dieser kompakte Statusdialog wird unter anderem beim Unterrichtsimport, Schülerfotoimport und bei der Schuljahr-Datenbereinigung verwendet.

Er zeigt Spinner, Prozentfortschritt, Fortschrittsbalken und die laufend eintreffenden Statusmeldungen. Fehlermeldungen werden hervorgehoben.

> **Wichtig:** Das Schließen des Dialogs beendet die Transaktion nicht. Der Prozess läuft im Hintergrund weiter und kann später über **Logs** kontrolliert werden.
