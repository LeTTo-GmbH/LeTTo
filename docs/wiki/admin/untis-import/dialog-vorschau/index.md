# Dialog: Untis-/Sokrates-Datei prüfen

Vor dem Speichern eines Imports zeigt LeTTo die geparsten Datensätze in einem Kontrollfenster. Der Dialog passt seine Spalten an den jeweiligen Importtyp an.

## Bereiche

- **Korrekt** – importierbare Datensätze; diese können einzeln oder gesammelt ausgewählt werden.
- **Fehlerhaft** – Datensätze, die nicht übernommen werden können; die Meldung beschreibt den erkannten Fehler.

Zusätzlich kann der Serverstatus anzeigen, ob ein Datensatz voraussichtlich neu eingefügt, aktualisiert oder unverändert behandelt wird.

Mit **Importieren** werden nur die aktuell ausgewählten korrekten Datensätze übernommen. **Abbrechen** beendet den Vorgang ohne Import.
