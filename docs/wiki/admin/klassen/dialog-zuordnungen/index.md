# Dialog: Klassenzuordnungen

Dieser reine Informationsdialog zeigt je nach aufgerufener Funktion einen der drei Bereiche einer Klasse:

## Unterrichtende Lehrer

Angezeigt werden Name, Login, unterrichtete Gegenstände und E-Mail-Adresse.

## Zugewiesene Schüler

Angezeigt werden Katalognummer, Name, Login und E-Mail-Adresse.

## Gegenstände

Angezeigt werden Gegenstandskürzel, Gegenstandsname und die zugeordneten Lehrer.

Der Dialog verändert keine Daten und wird mit **Schließen** beendet.
