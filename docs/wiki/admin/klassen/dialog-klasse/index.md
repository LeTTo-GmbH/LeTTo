# Dialog: Klasse anlegen oder bearbeiten

Der Klassendialog enthält die Stammdaten und Zuordnungen einer Klasse.

## Stammdaten

Bearbeitet werden können:

- Name
- Alias
- Jahrgang
- Schulstufe
- Schultyp
- Lehrplan
- Semestrierung
- Abteilung

Für Schultyp und Lehrplan kann auch **kein Schultyp** bzw. **kein Lehrplan** gewählt werden. Bei der Semestrierung stehen **Nicht semesterisiert**, **Wintersemester** und **Sommersemester** zur Verfügung.

## Zuordnungen

Für eine bereits gespeicherte Klasse zeigen Schaltflächen die Anzahl bzw. die vorhandenen Zuordnungen zu Lehrern, Schülern und Gegenständen. Bei einer neu angelegten Klasse stehen diese Informationen erst nach dem ersten Speichern zur Verfügung.

Mit **Abbrechen** wird der Dialog verworfen, mit **Speichern** werden die Klassendaten übernommen.
