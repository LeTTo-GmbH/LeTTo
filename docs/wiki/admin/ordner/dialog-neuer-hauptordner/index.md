# Dialog: Neuer Hauptordner

Der Dialog enthält ein einziges Pflichtfeld **Ordnername**. Mit der Enter-Taste oder **Speichern** wird der neue Hauptordner angelegt. Die Speichern-Schaltfläche ist nur aktiv, wenn ein nicht-leerer Name eingegeben wurde.

Mit **Abbrechen** oder dem Schließen-Symbol wird der Dialog ohne Anlage eines Ordners beendet.
