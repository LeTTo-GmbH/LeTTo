# Dialog: Vortragenden auswählen oder anlegen

Der Vortragenden-Dialog wird sowohl zum Hinzufügen als auch zum Ändern eines Vortragenden verwendet. Ein vorhandener Benutzer kann über die Suche gewählt werden. Falls erforderlich, kann ein neuer Vortragender mit Kürzel/Benutzername und Personendaten erfasst werden.

Die Auswahl wird erst mit Bestätigung an die Kursverwaltung zurückgegeben. Beim Entfernen vorhandener Vortragender gelten die Schutzregeln der Kursverwaltung: verwendete Zuordnungen oder der letzte verbleibende Vortragende können nicht ohne Weiteres gelöscht werden.
