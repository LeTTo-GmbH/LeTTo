# Dialog: Neuen Kurs anlegen

Der Dialog erfasst die grundlegenden Kursdaten für die zuvor ausgewählte Abteilung und das Studienjahr. Dazu gehören insbesondere Kursnummer bzw. Kursbezeichnung und ein Hauptvortragender.

Der Vortragende wird aus den verfügbaren Benutzern ausgewählt. Erst nach Bestätigung werden die Kursdaten an das Backend gesendet.
