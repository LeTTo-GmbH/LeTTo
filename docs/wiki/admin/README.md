# Struktur der Admin-Dokumentation

Jede dokumentierte Admin-Seite liegt in einem eigenen Unterordner. Dialoge/Modale liegen als weitere Unterordner direkt unter der zugehörigen Page. Screenshots werden ausschließlich in dem Ordner abgelegt, in dessen Markdown-Datei sie verwendet werden.

Die Einstiegsseite ist [index.md](index.md).
