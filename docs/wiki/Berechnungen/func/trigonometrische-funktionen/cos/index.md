## Name

`cos` – trigonometrische Funktionen.

## Detaillierte Beschreibung

Cosinus

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 1 Argumente.

Berechnet den Cosinus. Die mathematische Definition lautet `cos(x)`. Für reelle Werte liegt das Ergebnis zwischen -1 und 1.

## Syntax

```text
cos(x1)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `x1` | Parameter der Funktion. | Ganzzahl / komplexe Zahl | nein |

## Beispiele

**Beispiel:** `cos(%pi/2)`  
**Ergebnis:** 0

| Ausdruck | Ergebnis |
| --- | --- |
| cos(%pi/2) | 0 |
