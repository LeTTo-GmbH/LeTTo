# coth

## Name

`coth` – trigonometrische Funktionen.

## Detaillierte Beschreibung

Cotangens-Hyperbolicus

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 1 Argumente.

Berechnet den Cotangens hyperbolicus. Die mathematische Definition lautet `cosh(x)/sinh(x)`. Bei x = 0 ist der reelle Quotient nicht definiert.

## Syntax

```text
coth(x1)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `x1` | Parameter der Funktion. | Ganzzahl / komplexe Zahl | nein |

## Beispiele

**Beispiel:** `coth(1)`  
**Ergebnis:** 1.313035

| Ausdruck | Ergebnis |
| --- | --- |
| coth(1) | 1.313035 |
