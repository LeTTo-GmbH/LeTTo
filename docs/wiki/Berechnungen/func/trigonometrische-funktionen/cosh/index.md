# cosh

[Zurück zu Berechnungen](../../../index.md) · [Weitere Funktionen dieser Gruppe](../index.md)

## Name

`cosh` – trigonometrische Funktionen.

## Detaillierte Beschreibung

Cosinus-Hyperbolicus

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 1 Argumente.

Berechnet den Cosinus hyperbolicus. Die mathematische Definition lautet `(exp(x)+exp(-x))/2`. Für reelle Werte beträgt das Minimum 1 bei x = 0.

## Syntax

```text
cosh(x1)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `x1` | Parameter der Funktion. | Ganzzahl / komplexe Zahl | nein |

## Beispiele

**Beispiel:** `cosh(1)`  
**Ergebnis:** 1.5430806

| Ausdruck | Ergebnis |
| --- | --- |
| cosh(1) | 1.5430806 |
