## Name

`sech` – trigonometrische Funktionen.

## Detaillierte Beschreibung

Secans-Hyperbolicus, `sech(x)=1/cosh(x)`.

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 1 Argumente.

Berechnet den Sekans hyperbolicus. Die mathematische Definition lautet `1/cosh(x)`. Für reelle Werte liegt das Ergebnis über 0 und höchstens bei 1.

## Syntax

```text
sech(x1)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `x1` | Parameter der Funktion. | Ganzzahl / komplexe Zahl | nein |

## Beispiele

**Beispiel:** `sech(0)`  
**Ergebnis:** 1

| Ausdruck | Ergebnis |
| --- | --- |
| sech(0) | 1 |
