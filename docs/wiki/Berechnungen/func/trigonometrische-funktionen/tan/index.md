## Name

`tan` – trigonometrische Funktionen.

## Detaillierte Beschreibung

Tangens

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 1 Argumente.

Berechnet den Tangens. Die mathematische Definition lautet `sin(x)/cos(x)`. Bei Nullstellen von cos(x) ist der reelle Quotient nicht definiert.

## Syntax

```text
tan(x1)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `x1` | Parameter der Funktion. | Ganzzahl / komplexe Zahl | nein |

## Beispiele

**Beispiel:** `tan(%pi/4)`  
**Ergebnis:** 1
