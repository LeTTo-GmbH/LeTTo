## Name

`dechex` – Funktionen für Ganzzahlen.

## Detaillierte Beschreibung

Wandelt eine Zahl in eine Ganzzahl um und gibt sie als Hexadezimal-String mit Präfix `0x` aus.

Zahl in eine Ganzzahl wandeln und als Hexadezimal-String ausgeben

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 1 Argumente.

## Syntax

```text
dechex(A)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `A` | Parameter der Funktion. | String / Ganzzahl | nein |

## Beispiele

**Beispiel:** `dechex(12)`  
**Ergebnis:** "0xC"

| Ausdruck | Ergebnis |
| --- | --- |
| dechex(12) | "0xC" |
