## Name

`string` – Stringfunktionen.

## Detaillierte Beschreibung

Fügt mehrere Strings zusammen.

Alias/Kompatibilitätsname zu `strcat`.

Wandelt eine Zahl in einen String um.

### Anwendung und Besonderheiten

Die Übersicht führt diesen Namen als alternative Schreibweise bzw. kompatible Variante zu [strcat](../strcat/index.md). Maßgeblich sind die hier angegebenen Aufrufvarianten.

## Syntax

```text
string(...)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `wert1` | Wert bzw. Ausdruck für die Berechnung. | Zahl / Ausdruck | ja, beliebig oft |

## Beispiele

**Beispiel:** `string(123)`  
**Ergebnis:** "123"

| Ausdruck | Ergebnis |
| --- | --- |
| string(123) | "123" |
