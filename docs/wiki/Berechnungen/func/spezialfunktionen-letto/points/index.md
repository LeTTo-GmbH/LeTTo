# points

## Name

`points` – Spezialfunktionen LeTTo.

## Detaillierte Beschreibung

Berechnet die erreichbare Gesamtpunkteanzahl einer Frage

Berechnet die erreichbare Punkteanzahl einer Teilfrage. Als Parameter wird die Fragenummer als Ganzzahl angegeben.

## Syntax

```text
points(teilfrage)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `teilfrage` | Parameter der Funktion. | Ganzzahl | nein |

## Beispiele

**Beispiel:** `points()`  
**Ergebnis:** 2

| Ausdruck | Ergebnis |
| --- | --- |
| points() | 2 |

| Ausdruck | Ergebnis |
| --- | --- |
| points(0) | 1 |
