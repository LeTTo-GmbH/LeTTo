# pow

[Zurück zu Berechnungen](../../../index.md) · [Weitere Funktionen dieser Gruppe](../index.md)

## Name

`pow` – arithmetische Funktionen.

## Detaillierte Beschreibung

Potenzfunktion

### Anwendung und Besonderheiten

Die Implementierung erwartet genau 2 Argumente.

Berechnet die Potenz der Basis mit dem angegebenen Exponenten. Für einen positiven ganzzahligen Exponenten entspricht dies einer wiederholten Multiplikation. Ein negativer Exponent bildet die entsprechende Kehrwertpotenz.

## Syntax

```text
pow(basis, exponent)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `basis` | Parameter der Funktion. | Zahl / Ausdruck | nein |
| `exponent` | Parameter der Funktion. | Zahl / Ausdruck | nein |

## Beispiele

**Beispiel:** `pow(2,3)`  
**Ergebnis:** 8

| Ausdruck | Ergebnis |
| --- | --- |
| pow(2,3) | 8 |
