## Name

`factorial` – statistische Funktionen.

## Detaillierte Beschreibung

Liefert die Fakultät einer positiven ganzen Zahl

Für eine nicht negative ganze Zahl `n` ist die Fakultät `n! = 1*2*...*n`; für 0 wird 1 geliefert. Der Code erwartet einen Ganzzahlparameter und weist negative Werte sowie Werte ab 1000000000 zurück. Das Ergebnis wird als BigInteger berechnet.

## Syntax

```text
factorial(wert)
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
|---|---|---|---|
| `wert` | Wert bzw. Ausdruck für die Berechnung. | Zahl / Ausdruck | nein |

## Beispiele

**Beispiel:** `factorial(5)`  
**Ergebnis:** 120

| Ausdruck | Ergebnis |
| --- | --- |
| factorial(5) | 120 |
