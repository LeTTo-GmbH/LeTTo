## Name

`%e` – Konstanten.

## Detaillierte Beschreibung

Eulersche Zahl.

**Wert:** 2.718281828459045

### Anwendung und Besonderheiten

Konstantennamen beginnen mit `%`. Ohne Prozentzeichen wird der Name laut Übersicht als Variable mit dem Konstantenwert verwendet.

## Syntax

```text
%e
```

## Parameterbeschreibung

Keine Funktionsparameter; die Konstante wird über ihren Namen verwendet.

## Beispiele

```text
x:%e
```

Weist den Konstantenwert der Variablen `x` zu.
