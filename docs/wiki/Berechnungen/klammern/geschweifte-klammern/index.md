## Name

`{ }` – Klammern.

## Detaillierte Beschreibung

Kennzeichnen im Angabetext Namen von Datensätzen. Sie sind in diesem Zusammenhang eine Einbettung in den Angabetext, keine arithmetische Rechenoperation.

## Syntax

```text
{R1}
```

## Parameterbeschreibung

Der Klammerinhalt enthält Ausdrücke, Argumente, Elemente oder einen Datensatznamen entsprechend der beschriebenen Klammerart.

## Beispiele

| Ausdruck | Ergebnis |
| --- | --- |
| `{R1}` | Wert des Datensatzes R1 im Angabetext. |
