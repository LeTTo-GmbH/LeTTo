## Name

`( )` – Klammern.

## Detaillierte Beschreibung

Klammern mathematische Ausdrücke und begrenzen die Argumentliste einer Funktion.

## Syntax

```text
(4+5)*2
```

## Parameterbeschreibung

Der Klammerinhalt enthält Ausdrücke, Argumente, Elemente oder einen Datensatznamen entsprechend der beschriebenen Klammerart.

## Beispiele

| Ausdruck | Ergebnis |
| --- | --- |
| `(4+5)*2` | 18 |
