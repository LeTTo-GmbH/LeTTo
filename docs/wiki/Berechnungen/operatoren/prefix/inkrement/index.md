# ++

[Zurück zu Berechnungen](../../../index.md)

## Name

`++` – Prefix-Operatoren.

## Detaillierte Beschreibung

Inkrement von Ganzzahlen. Die Parserpriorität beträgt **130**; die Bindung ist prefix.

### Anwendung und Besonderheiten

Die Operatoren des internen Parsers sind teilweise anders als in Maxima definiert. Für eine symbolische Maxima-Berechnung sind gegebenenfalls die entsprechenden Funktionen zu verwenden.

## Syntax

```text
++x
```

## Parameterbeschreibung

| Parameter | Beschreibung | Möglicher Datentyp | Optional |
| --- | --- | --- | --- |
| x | Operand bzw. Ausdruck. | Variable | nein |

## Beispiele

| Ausdruck | Ergebnis |
| --- | --- |
| ++x | erhöht x um eins und gibt das Ergebnis nach der Erhöhung zurück |
