# LTO-Beispieldateien

Beispiele im LeTTo-Austauschformat `.lto` (Formatbeschreibung: [docs/lto](../docs/lto/index.md)).
Alle Dateien sind gültig nach `docs/lto/letto-lto/lto-v1.xsd` und `docs/lto/letto-lto/validate_lto.py`.

| Datei | Inhalt |
|---|---|
| 01-berechnung-ohmsches-gesetz.lto | Mehrfachberechnungsfrage mit zwei Datensätzen, Maxima-Feld und Einheiten |
| 02-auswahl-und-text.lto | Single-Choice, Multiple-Choice mit negativer Bewertung und Texteingabe |
| 03-kategorie-mit-unterordner.lto | Fragesammlung mit Unterordner |
| 04-ki-test-mechanik.lto | Von einer KI nur mit dem Skill `letto-lto` erzeugte Fragesammlung (Kinematik, freier Fall, Newton) |

Die Dateien 01–03 sind Kopien der Beispiele aus `docs/lto/letto-lto/beispiele/`.
